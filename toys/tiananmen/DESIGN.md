# 天安门 · 国庆明信片

## Overview

仅适用于 toys/tiananmen/。用户已拒绝微缩风格，方向改为写实建筑：城楼是主体，界面退到四周，使用天空光与广场低视角。当前已用爱给网现成建筑模型替换旧程序化重建，用户要求的“很真实”尚未确认达成。

## Colors

日景界面用蓝灰文字、暖白控制面板与朱红烟花按钮；夜景用蓝黑背景与暖白文字。建筑沿用源模型红墙、石材和彩画贴图；屋瓦手动改为金色标准材质，未等价恢复所有 V-Ray 程序材质。

## Typography

仅保留系统中文无衬线控件（PingFang SC、Microsoft YaHei），桌面按钮 12px、手机 11px。祝福标题、说明、日期、印章与提示词已按用户要求移除。

## Layout

城楼与金水桥占满画面，左上仅返回、右上仅保存。底部居中单行六个短标签操作，右下保留“模型来源 · 非商用”链接。手机保持单行操作；700px 断点切换更宽视场与更远机位。

## Elevation & Depth

本地 Three.js 加载约 87.8MB 的 assets/tiananmen-imported.glb，配合天空、水面、阴影与石材法线。转换修复 123 个 V-Ray diffuse 连接，恢复 72 张 diffuse 贴图并将其最长边限制为 1024 像素；部分植被与石狮减面，同材质槽部件合并。场景倍率为 1.7，未经测绘验证。独立复查认为旧材质、屋顶与檐下结构问题已 resolved，视角与环境仍为 partial。瓦偏哑光、旗深暗僵硬、石材重复明显，属资源与转换限制；当前不是照片级真实。模型已在本地载入且无 console error，加载性能未实测。

## Components

控制支持昼夜、近看城楼、俯瞰广场、环游、恢复视角与烟花。OrbitControls 支持拖动与双指缩放；方向键调整视角，Home 恢复，+/- 缩放。保留当前场景 PNG 保存，已删除提示词展开与复制功能。左侧标语由 Canvas 修正，去掉旧 JS 重复城楼红旗、标语与铺地；保留广场国旗与烟花效果。

## Do's and Don'ts

- Do 以 SOURCES.md 与 assets/imported-model-check.json 记录当前模型来源、转换与限制；旧照片贴图不用于当前导入模型。
- Don't 将现成模型及 1.7 倍率称为测绘结果。
- Don't 商用该资源；源页面标注仅限非商业用途，再分发授权尚未核实，不应直接发布下载包或转换模型。
- Do 将验收范围与用户接受程度分开记录：独立 reviewer 本次模型替换 verdict 为 ship，不代表用户已接受写实程度。新桌面 1280×720、手机 390×844 截图为 .impeccable/review/tiananmen-realistic/imported-desktop.jpg 与 imported-mobile.jpg；手机裁切两侧标语，但主体屋顶完整。
- Do 使用 node toys/tiananmen/check.mjs 检查当前模型与合集入口；既有设计检测器为 regex-only 降级模式，不证明计算对比度或写实程度已验证。

## 城楼旗杆

按用户要求暂时隐藏导入模型的八面红旗，原 GLB 保留不改，以便恢复。城楼两侧保留原模型的金属旗杆，不重复添加旗杆。广场五星红旗沿用已有动画；系统开启减少动态效果时旗帜与水面停止动态更新。
